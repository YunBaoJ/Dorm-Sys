# 基于SpringBoot+Vue的学生宿舍管理系统开题报告

## 1. 选题意义
随着高校学生规模的不断扩大和宿舍管理事务的日益增多，传统依靠纸质登记、人工统计和分散表格维护的管理方式，已经难以满足现代高校对于住宿信息动态更新、宿舍资源查询、入住调整、报修处理和数据统计等实际需求。宿舍管理工作涉及学生、楼栋、宿舍、床位、班级、入住状态等多类繁杂信息，如果缺少统一的信息化平台，极容易出现数据重复录入、查询效率低下、记录更新不及时和管理过程不规范等问题。

因此，开发一套基于SpringBoot和Vue的学生宿舍管理系统具有重要的现实意义。本系统旨在利用现代Web前后端分离技术，实现宿舍管理业务的可视化、流程化和规范化。通过该平台，宿舍管理员和学校管理层能够集中维护学生与宿舍信息，高效处理入住分配、宿舍调整与报修申请。这不仅能大幅提升日常管理效率，降低人工管理带来的错误率，还能为学生提供便捷的后勤服务查询与报修渠道，从而推动高校后勤管理的数字化与智能化建设。

## 2. 国内外研究现状概述
随着信息技术的飞速发展与智慧校园建设的推进，国内外高校在学生后勤与宿舍管理方面的信息化程度不断提高。在国外，很多知名高校已经普及了成熟的校园综合管理系统（如基于ERP架构的校园系统），宿舍管理作为其中一个子模块，早已实现了高度的自动化、自服务化与移动化，学生可以通过线上系统完成从选房、缴费到报修的全流程操作。

在国内，近年来各类高校也在积极推进“智慧校园”建设。早期的宿舍管理系统多采用传统的C/S架构或基于JSP/ASP等技术的B/S架构，这些系统虽然在一定程度上解决了手工管理的弊端，但在系统扩展性、页面交互体验以及前后端耦合度上存在局限。目前，随着微服务架构与前后端分离开发模式的流行，采用Spring Boot作为后端服务端框架、Vue或React作为前端界面的开发架构逐渐成为主流。这种架构不仅提高了系统的响应速度和用户体验，也使得系统的维护与升级更加便捷。文献研究表明，国内对于宿舍管理系统的研究正在向智能化、移动端化（如微信小程序结合）以及大数据分析方向发展，以进一步优化资源配置和提高校园安全管理水平。

## 3. 主要研究内容
本项目主要围绕高校学生宿舍管理业务展开，设计并实现一个前后端分离的B/S架构信息管理系统。主要研究内容包括：
1. **需求分析与系统设计**：结合学生宿舍管理业务，分析系统角色（管理员、宿管和学生），明确业务流程和功能需求。设计包括用户登录验证、数据可视化统计、学生信息管理、宿舍资源管理、入住分配与退调管理、宿舍报修管理及公告发布等核心功能模块。
2. **数据库设计**：根据业务需求设计合理的E-R模型，在MySQL中建立包括学生表、宿舍表、楼栋表、床位表、入住记录表、报修表、用户与权限表等在内的数据表，确保数据约束和主外键关系合理。
3. **后端接口设计与实现**：基于SpringBoot框架搭建后端服务端，利用MyBatis/MyBatis-Plus实现持久层数据访问。开发用户鉴权拦截、各类数据的增删改查RESTful接口，并处理各种业务逻辑（如床位冲突校验）和数据统计，保证接口数据格式统一。
4. **前端交互界面开发**：利用Vue框架、Axios网络请求库构建系统的前端页面。实现登录路由控制、表单数据校验、表格分页展示、图表统计可视化以及弹窗编辑等良好的交互体验。
5. **系统联调与测试**：完成前后端接口联调，对学生信息管理、宿舍分配、入住调整、报修处理等核心功能进行全面测试，修复系统缺陷，确保系统数据一致性和稳定可靠运行。

## 4. 拟采用的研究思路（方法、技术路线、可行性论证等）
**研究思路与方法：**
本项目采用软件工程的生命周期方法，按照“需求分析-总体设计-详细设计-编码实现-系统联调-部署测试”的流程推进。在开发过程中采用迭代开发的思想，优先实现核心的宿舍与学生信息流转，再逐步完善报修、统计等外围功能模块。

**技术路线：**
1. **前端技术**：使用Vue（推荐Vue 3）框架搭建单页面应用（SPA），结合Vue Router进行页面路由管理，使用Vuex/Pinia进行状态管理，通过Axios与后端进行异步数据交互，UI层采用Element Plus（或Element UI）等成熟组件库以提升开发效率并保证界面美观。
2. **后端技术**：采用Java语言，核心框架使用Spring Boot，极大地简化了Spring应用的初始搭建和配置过程。持久层选用MyBatis或MyBatis-Plus框架，实现对象关系映射。
3. **数据库与开发环境**：数据库选用MySQL进行关系型数据存储。使用IntelliJ IDEA或VS Code作为主要开发工具，Git进行版本控制，Maven进行后端依赖管理，Node.js及npm进行前端依赖管理。

**可行性论证：**
1. **技术可行性**：SpringBoot和Vue均为当前市场非常成熟、社区活跃且文档完善的开源主流框架，前后端分离架构已被业界广泛验证，技术路线完全可行。
2. **操作可行性**：系统最终提供基于浏览器的Web界面，交互友好，操作直观易懂，管理员和学生均无需安装额外客户端，具备极高的操作便捷性与可行性。
3. **经济可行性**：系统开发所使用的IDEA/VS Code、MySQL、Vue等软件与框架均为开源或免费工具，开发成本极低。
