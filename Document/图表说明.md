### 各阶段说明

| 阶段 | 主要工作 |
|------|----------|
| 1. 需求分析与设计 | 明确系统功能需求、用户角色（管理员、宿管、学生）、业务流程，设计数据库E-R模型 |
| 2. 系统架构设计与技术选型 | 确定SpringBoot+Vue前后端分离架构，选择MySQL数据库，规划系统模块划分 |
| 3. 前端开发 | 使用Vue3+Element Plus实现页面布局、表单校验、表格分页、数据图表展示等交互功能 |
| 4. 后端开发 | 使用SpringBoot构建RESTful API，实现用户认证、数据增删改查、业务逻辑处理 |
| 5. 系统集成 | 前后端接口对接，完成数据交互联调，确保接口格式统一 |
| 6. 系统测试 | 功能测试、接口测试、性能测试，验证核心业务流程，修复缺陷 |
| 7. 本地部署 | 在开发环境完成系统部署，准备答辩演示材料 |

### 架构说明

| 层次 | 技术栈 | 职责描述 |
|------|--------|----------|
| **用户层** | 浏览器 | 三类用户角色通过浏览器访问系统，根据权限进入不同功能界面 |
| **前端层** | Vue3 + Element Plus + Axios + Vue Router + Pinia | 负责页面渲染、用户交互、数据展示、路由管理、状态管理 |
| **后端层** | SpringBoot + MyBatis-Plus + JWT + Maven | 负责业务逻辑处理、RESTful接口提供、用户认证、权限校验、数据持久化 |
| **数据层** | MySQL | 存储所有业务数据，支持数据查询、统计分析、数据一致性保障 |

### 数据流向

```
用户操作 → 前端页面 → Axios请求 → 后端API → MyBatis-Plus → MySQL数据库
    ↑                                                          ↓
    └──────────── 页面渲染 ← JSON响应 ← Controller ← Result ←──┘
```

## 在开题报告中的使用位置

这两张图放在"拟采用的研究思路（方法、技术路线、可行性论证等）"部分的"技术路线"之后：

```markdown
### 技术路线

1. **前端技术**：使用Vue3框架搭建单页面应用（SPA），结合Vue Router进行页面路由管理，使用Pinia进行状态管理，通过Axios与后端进行异步数据交互，UI层采用Element Plus组件库以提升开发效率并保证界面美观。

2. **后端技术**：采用Java语言，核心框架使用Spring Boot，极大地简化了Spring应用的初始搭建和配置过程。持久层选用MyBatis-Plus框架，实现对象关系映射。

3. **数据库与开发环境**：数据库选用MySQL进行关系型数据存储。使用IntelliJ IDEA或VS Code作为主要开发工具，Git进行版本控制，Maven进行后端依赖管理，Node.js及npm进行前端依赖管理。

**图1   开发与部署流程**

图1展示了本系统开发与部署流程的七个主要阶段：首先进行需求分析与设计，明确系统功能与数据模型；随后完成系统架构设计与技术选型，确定采用SpringBoot+Vue的前后端分离方案。在此基础上，前后端开始并行开发，各自实现相应功能模块；开发完成后进行系统集成，将前后端对接联调；接着开展系统测试，验证功能完整性与稳定性。最后，在本地环境完成系统部署，为毕业答辩提供可运行的演示版本。该流程环环相扣，确保了项目从设计到实现的顺利推进。

**图2   系统架构图**

图2展示了本系统采用的分层架构设计，整体分为四个主要部分：用户通过浏览器访问系统，根据身份权限进入不同界面。前端基于Vue.js框架开发，通过响应式组件实现动态交互，利用路由导航进行页面切换，并通过API调用与后端通信。后端采用SpringBoot框架，按业务领域划分为六个核心模块：用户认证、学生管理、宿舍管理、入住管理、报修处理及数据统计，各模块职责明确，协同处理业务逻辑。系统使用MySQL数据库进行数据持久化存储。该架构实现了前后端分离，保证了系统的可维护性和扩展性。
```
